# 地图样式实现与视觉验收

## 目标与范围

参考 Apple 官方标准地图截图由视觉检查脚本生成到根目录 `images/`，作为本地输出由 Git 忽略，不随仓库保存。

机器记录：`../experiments/map-style-evidence.json`、`../experiments/map-style-city-evidence.json`、`../experiments/map-views-browser-evidence.json`。

双岸河谷截图使用 `scripts/grow_valley.py` 生成并在第 12 个月保存的场景，包含 23 条道路和 194 栋建筑。界面显示的内容均来自该场景。
