# 实验与验证资料

本目录保存模拟脚本输出、历史城市场景、测量报告、浏览器检查结果和日志。它不再承担应用内置案例或固定测试输入的存放职责。

- 应用已生长案例：[examples](../examples/README.md)。
- 测试与视觉检查固定输入：[tests/fixtures](../city-planner/tests/fixtures/README.md)。
- 项目规则、机制和实现状态：[docs](../docs/README.md)。

`grow_blocks.py` 等脚本可以继续向本目录生成候选存档与报告；这些输出不会自动替换应用内置案例。历史场景可能采用旧城市或地形格式，不能据此保证当前代码可直接加载。

普通应用运行不读取本目录的历史资料。复现实验时，可以通过相应脚本的输入参数或手动导入选择保留的历史场景。

新生成内容默认由根目录 `.gitignore` 忽略，本说明文件除外。已有 Git 跟踪的历史资料继续保留；忽略规则不会自动取消跟踪。需要纳入版本控制的应用案例和测试输入应放入各自专用目录。
