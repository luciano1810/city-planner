# 交通建筑、CBD 摩天楼与随机停车设施

## 操作

建设面板新增“交通建筑”，提供机场、港口、火车站。

- 选择类型后，移动鼠标预览占地，点击地图放置。
- 机场和港口可按 R 每次旋转 15°，也可以直接输入 0–359° 朝向。
- 支持紧凑、标准、大型三种规模，以及自定义名称。
- 港口的箭头表示海侧。陆侧堆场必须位于平缓陆地，海侧必须有足够水面。
- 火车站在附近地面铁路上自动对齐，要求铁路足够长且站台区段较直。
- 地图点选建筑可查看占地、建设费用、道路接入以及关联站点，支持拆除、撤销、重做和存档。

## 已实现

| 类型 | 建筑与生成规则 |
| --- | --- |
| 机场 | 用户选址；跑道、滑行道、标线、停机坪、停放飞机、航站楼、塔台、机库、进场连接及夜间跑道灯 |
| 港口 | 用户沿岸选址；堆场、集装箱、仓库、码头、装卸起重机和泊位船舶 |
| 火车站 | 用户选址并吸附铁路；站房、站台、雨棚、轨道、站前区域；自动关联可用于线路的客运站点 |
| CBD 摩天楼 | 在已有 CBD 边界内自动开发；36–52 层、三类退台轮廓、幕墙；新建或扩建现有办公楼，施工结束后才增加可用容量 |
| 露天停车场 | 月度自动生长，在已开发街区附近随机选择可接入的空闲地块；含车位、通道和停放车辆 |
| 停车楼 | 与露天停车场共同随机生成；3–5 层、开放式停车层与屋顶车位；CBD 附近出现概率更高 |

机场、港口和车站用地会阻止后续道路、普通开发与设施覆盖。拆除车站时，建筑新建的站点同步移除，既有站点保留；依赖被删除站点的线路失效。

CBD 仍由原有办公集聚、实际就业、规模、可达性和持续期规则识别。摩天楼仅在其边界内选址，保留办公容量与施工周期，每个 CBD 的地标数量有上限。普通地块不会随机长出 CBD 摩天楼。

停车设施在至少有六栋已交付建筑后开始出现，约每十六栋建筑配一处，避免与已有停车设施过近。选址与类型使用存档种子和模拟月份生成，重载同一存档不会重新随机。关闭自动配套或停止发展时，不新增停车设施。

机场和港口此次实现建筑、选址、占地保护和维护费用；航班、海运线路和装卸运输尚未接入。停车位是规划容量，停放车辆是场景细节，尚未执行逐车位停车分配。

## 验证

- 79 项相关 Python 检查通过，覆盖既有城市、街区、更新、交通连接与新增特殊建筑。
- 8 项 JavaScript 几何及建筑布局检查通过。
- 浏览器实际通过地图点击放置三类交通建筑，并核对关联铁路站点。
- WebGL 画面、Canvas 回退画面和机场夜间照明均已截图检查，浏览器未出现页面脚本错误。
- 验证场景形成 CBD 后自动开发出一栋 38 层、148.2 米摩天楼，随机生成五处露天停车场和五处停车楼。

验证场景预置了办公规模和就业条件，用于检查自动触发与建筑外观，不作为从空城自然发展的性能结果。完整存档在 `docs/experiments/special-buildings-city.json`，可通过“导入 JSON”打开。

截图在 `docs/images/special-airport.png`、`special-port.png`、`special-train-station.png`、`special-cbd-parking.png`、`special-parking-lot.png` 和 `special-parking-garage.png`。检查记录在 `docs/experiments/special-buildings-ui.json`。

核心实现为 `backend/city/special_buildings.py` 与 `renderer/special-buildings.js`，通过现有城市引擎、建造界面和两套渲染路径接入。
