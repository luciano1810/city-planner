# 建成建筑外观

`renderer/building-appearance.js` 为既有建筑按固定 ID 选择外观，包含住宅 14 套、办公 10 套、商业 9 套、工业 7 套、仓储 6 套，共 46 套。施工状态、人口变化和重载不改变风格。材质使用独立种子，原有体量选择保持稳定。

## 体量与材质

- 适合的矩形住宅加入错层、L 形、U 形组合；办公楼加入双塔、L 形和分级退台；商业楼加入围合中庭和露台组合。上下楼体共用现有几何、阴影和施工进度接口。特殊地标、复杂多体量和过小地块沿用既有布局。
- 原始 footprint、楼层、高度、容量和模拟数据保持原值；变化属于显示层。最高体量保持建筑总高度，分块不越出原始可建矩形。
- `architecture-facades-atlas.png` 是 4×4 立面图集：6 格住宅、2 格商业、4 格办公、4 格工业/仓储。每格包含两个窗跨、两个楼层。按墙长和实际楼层拟合，不使用随机纹理合成打散窗洞。贴图生效后跳过原有程序窗格，避免重影。
- `architecture-materials-v2.png` 增加 16 类立面，合计 32 格：红砖、砂岩、带百叶窗的灰泥、板岩、木挂板、陶板、预制混凝土、绿色马赛克、青铜金属、铜绿板、洞石、花岗岩、蓝色压型钢板、旧厂房砖、浅色金属板、白瓷砖。每格同样采用两窗跨、两楼层，各有原色、暖色、冷色三种有限色调。夜间窗格采用相应窗宽，避免在实墙上发光。
- 平屋顶按用途提供四种稳定表面色调，区分灰色防水屋面、浅色混凝土和暖色砾石屋面。原有屋顶设备、绿化、坡屋顶结构和空间避让保持有效。
- `architecture-roof-zones.png` 是 2×2 透明屋顶组合图集：屋顶花园、玻璃中庭、机械设备区、太阳能阵列。每块平屋顶最多两组，自动避让高层体量、原有屋顶设备、女儿墙和其他组合；坡屋顶继续采用原有设备布置。
- 两张新增图集使用内置 ImageGen 生成，完整提示词与 PNG 一同保存在 `renderer/assets/architecture-facades.prompt.txt` 和 `architecture-roof-zones.prompt.txt`。
- 原屋顶三角面在 Canvas 中成对合并为四边形，消除屋面内部抗锯齿对角缝。原网格仍用于开发用 WebGL 路径。

## 按地块轮廓生成体量

`building-shapes.js` 使用地块 ID 固定随机种子。规整地块约 76% 沿用矩形组合，13% 切角，8% 圆角，其余仅对宽敞的办公和商业地块生成椭圆楼体。异形地块约 52% 沿用矩形分块，20% 沿合法建筑轮廓，18% 局部切角，10% 沿轮廓生成底座并保留上层退台。过窄、过小和特殊地标沿用原体量。

轮廓来自已有建筑 footprint，不扩张到地块退界外；只改变显示，不写入容量或建筑存档。凹形屋顶按实际轮廓三角化，设备同时检查角点和凹口边界。Canvas 阴影保留凹口；WebGL 使用同一多边形体量并沿各墙面生成窗格。异形屋顶暂用平顶与独立设备，不叠加矩形屋顶组合图块。

## 缓存和限制

默认 Canvas 精细视图将外墙细节和屋顶组合写入原有 48 MiB、256 项建筑 LRU。立面按 256 至 8 像素预过滤并惰性缓存，采用最多 96 张的 LRU，屋顶组合最多 4 张。色调仅在最大分辨率生成一次，缩小层级不会重复染色。贴图加载版本纳入对象缓存键，加载完成请求重绘。每栋建筑独立判断所属立面图集是否可用，新增图集失败或屋顶图片未加载时，既有立面仍可显示；不可用的立面沿用基础材质和程序窗格。远景保留轻量建筑体量，不制作细节贴图。新增立面与屋顶组合主要用于默认 Canvas 路径；开发用 WebGL 路径共用体量与屋顶颜色，保留其原立面材质与屋顶设备。

## 验证

在 `city-planner/` 下执行：

```bash
npm run test:architecture
npm run test:architecture:visual
node scripts/check-building-shapes.cjs
```

视觉脚本需可用的 Playwright/Chrome；可通过 `NODE_PATH` 和 `CHROMIUM_EXECUTABLE` 指定现有安装。脚本使用独立临时存档目录，输出到 `output/playwright/building-appearance/`，包括白天、傍晚、旋转近景和缓存检查。单位检查覆盖稳定外观、几何边界、上下体量和设备避让、存档数据不变、屋顶及 LOD 回归。

地块轮廓视觉检查输出到 `output/playwright/building-shapes/`，覆盖矩形、切角、梯形、L 形、凹形与退台，所有样例均由默认种子规则生成。

## 高层细节

12 层起增加底部大堂、顶部收边；住宅使用连续阳台与竖向分隔，办公楼增加成对竖梃、分段反光和每十层的设备百叶带。CBD 地标也应用这些立面细节。程序窗格上限从每段 12 排提高至 64 排，避免摩天楼显示成少数巨型窗洞；夜间窗光避让设备层、首层覆盖区和顶部收边。

最高办公屋顶可生成阶梯尖杆、百叶机房或双翼框架三种冠部，退台屋顶不再重复放置塔冠。细节增强用于默认 Canvas 精细视图，屋顶冠部网格与 WebGL 共用。运行 `node scripts/check-building-highrises.cjs` 可查看 24–52 层的住宅、双塔办公、退台办公与 CBD 实际渲染截图。
