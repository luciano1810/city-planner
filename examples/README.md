# 内置城市案例

本目录保存应用“城市案例”界面使用的已生长存档。正常启动、新建地图、从空路网开始以及实景街区构建不依赖这些文件。

| 存档 | 入口或加载顺序 |
| --- | --- |
| `blocks-v8-final.json.gz` | 小街区布局案例 |
| `valley-v5-final.json.gz` | 已生长河谷城市，首选 |
| `valley-v4-final.json.gz` | 首选文件不存在时使用 |
| `valley-final.json.gz` | 前两个河谷文件都不存在时使用 |

加载入口见 [城市服务](../city-planner/backend/city/service.py)。备用仅在文件不存在时触发，不用于绕过损坏或不兼容的首选文件。

这些文件保留历史数据，部分旧地形不具备当前要求的 `float32-le-meters` 编码，可能无法加载；目录整理不转换地形或重建案例。替换内置存档前应确认当前模型能够导入并从对应界面打开。

模拟脚本仍向 `experiments/` 输出存档和报告。确认生成结果适合作为内置案例后，再明确更新本目录文件，避免日常实验覆盖应用资源。
